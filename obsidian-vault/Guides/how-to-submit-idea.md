# How to Submit an Idea

## Overview

An idea is a proposed solution to a problem. Before submitting, check if a similar idea already exists using the search feature.

## Step-by-Step Guide

### Step 1 — Write a clear title

The title should describe your solution in one sentence. Good titles are specific and action-oriented.

Example: "Automated weekly summary emails for team subscriptions"

### Step 2 — Describe the problem you are solving

Link your idea to one or more existing problems on the platform. If no matching problem exists, create one first.

### Step 3 — Write your description

Explain what your idea does, how it works, and why it is valuable. Aim for 2-3 paragraphs. Include any relevant context or prior art.

### Step 4 — Add tags

Tags help others discover your idea. You can either select from existing tags already used on the platform, or type a new tag name to create one. Choose up to 5 tags that describe the topic, technology, or business area.

### Step 5 — Save as draft or publish

Save as draft to continue editing later. Publish when ready to share with the community.

Published ideas are visible to all authenticated users and can receive comments and votes.

## Lifecycle Stages

After publishing, your idea moves through stages:

- **Ideation** — initial proposal, gathering feedback
- **Prototyping** — active development or experimentation
- **Completed** — shipped or implemented
- **Paused** — temporarily on hold
- **Archived** — no longer active
